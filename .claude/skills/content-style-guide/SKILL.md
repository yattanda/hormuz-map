# コンテンツスタイルガイド

このスキルはニュース記事の執筆・メディア選定・文章表記を行う際に使用する。

---

## 日付フォーマット統一

日付の書き方は次の3つに絞る（2026-10-07〜・`tools/display-unify-design.md` K5）。**新しく書く分から揃える。過去の記録は書き換えない。**

| 使う場面 | 形 | 例 |
|---|---|---|
| (i) ページ・区域をいつ更新したか | `YYYY年M月D日 HH:MM JST` | `2026年10月6日 09:43 JST` |
| (ii) 文中の短い形（出来事の日・出典の日付） | `M/D HH:MM JST`。日付だけなら `M/D` | `10/6 09:43 JST`・`10/6` |
| (iii) 数値がいつ時点か | `YYYY年M月D日時点` | `2026年9月29日時点` |

- 月・日はゼロ埋めしない。時刻は24時間制で `HH:MM`
- 機械が読む値は ISO 形式（`dateModified` は `2026-10-06T09:43:00+09:00`、`<time datetime>`・sitemap の `lastmod` は `2026-10-06`）
- 既存のまま変えない例外：`news_data.json` の `updated`（`2026年10月6日 09:43 日本時間JST`。JS と検査がこの形で読む）、
  更新履歴の `log-date`（`2026/10/06 09:43`）、TICKER とハブの `M/D HH:MM`

- タイムスタンプの日付は必ずユーザーがプロンプトで明示したものを使用する
- Claude が自動推測した日付は使わない
- 日付が明示されていない場合は作業前にユーザーに確認する
- 関連最新ニュースおよび現地メディア視点の記事日付は、現地時間と JST（日本標準時）の両方を記載する

## メディア掲載ルール（カラム別）

| カラム | 使用可 | 使用不可 |
|---|---|---|
| 📰 関連最新ニュース | 上記「利用可メディア」（ただし中東系・アルジャジーラを除く） | 現地中東系メディア・アルジャジーラ |
| 🌐 現地メディア視点 | 現地中東系メディア・アルジャジーラを含む全メディア | 利用不可メディア（日本）|

### 現地中東系メディアの定義（例）

- PressTV（イラン国営）
- Al Arabiya（サウジ系）
- The National（UAE系）
- Al Jazeera（カタール系）

これらは「📰 関連最新ニュース」カラムには掲載不可。「🌐 現地メディア視点」カラムにのみ掲載可。

### フッターの「データソース」表記（2026-10-01 追加）

- `docs/hormuz/index.html` の `<footer>` 末尾の「データソース：…」には、**利用不可メディアを書かない**
- 名前を挙げるのは、実際に出典として使っている発表元・媒体だけにする（使っていない媒体名を並べない）。
  名前を足すときは、`docs/hormuz/index.html` と `docs/data/news_data.json` に実際の出典があることを検索で確かめる
- 【経緯】初期版から「テレ朝NEWS・時事通信・FNNプライム・BBC日本語・Reuters日本語・東洋経済・NRI（野村総研）・IEA」の
  固定表記が残っていた。テレ朝は利用不可メディアで、テレ朝・東洋経済・NRI は出典としての使用が0件だった（2026-10-01 実測）

## 数値・価格の書き方（2026-10-06 追加）

- 数値（量・割合・件数）には**期間**と**基準**を添える
  - OK：「Kplerの速報では、9月最終週の4日間、中東の原油輸出が日量1,950万〜2,250万バレルと戦前の平均（約1,800万）を上回った」
  - NG：「9月の中東の原油輸出は戦前を上回った」（期間が抜け、意味が変わる）
- 集計元（Kpler・Vortexa・政府など）と、それを伝えた媒体を分けて書く（「Kplerの集計（Al Jazeera 10/5）」）
- 2つの数値が合わないときは「食い違う」と書いて公開しない。期間・対象・基準の違いで説明できるなら、その違いを書く。説明できなければ載せない
- 原油価格は終値だけを書き、「終値」と限月（ブレント12月物など）と出典2つを添える。日中の値と混ぜない
- 確認の手順は `daily-site-update` の「数値の扱い」と「2.5 裏取り」

## 用語統一ルール

### ルール：「封鎖」には必ず主語を付ける（2026-10-02 拡張）

「封鎖」「二重封鎖」は、**誰が・どこを**止めているのかを必ず書く。主語の読めない「封鎖」「封鎖中」「封鎖継続」「二重封鎖」は NG。
（「二重封鎖」は 2026-04-30 からのルール。同じ語が「イランと米軍」「ホルムズと紅海側」の2つの意味で混ざった前例がある。
2026-10-02 に単独の「封鎖」と日数の呼び名へ広げた。経緯と方針は `tools/blockade-term-policy.md`）

| 指すもの | 正しい表記 | 書かない |
|---|---|---|
| イランがホルムズ海峡の通航を止めている・絞っている | イランによるホルムズ海峡の通航制限（閉鎖） | ホルムズ封鎖、封鎖中 |
| 米軍がイランの港に出入りする船を止めている | 米軍の対イラン海上封鎖 | 米封鎖、封鎖 |
| 上の2つが重なっている | イラン・米国による二重封鎖（Iran-US dual blockade） | 二重封鎖 |
| ホルムズ海峡と紅海側（バブ・エル・マンデブ海峡）の両方が通れない | ホルムズ・紅海の二重封鎖 | 二重封鎖 |
| 開戦（2026-02-28）からの日数 | 危機N日目 | 封鎖N日目、二重封鎖N日目 |

- 発言を引用するときは、発言者と、相手が何を指して言ったのかを添える
  （例：イラン副外相は「米国が海上封鎖を解くまで海峡の閉鎖を続ける」と述べた）
- 「危機N日目」は開戦からの経過日数で、特定の封鎖が続いた日数ではない。「封鎖がN日続いている」という意味では使わない
- 過去に公開した速報本文（`archive_timeline.json`・`update_log.json`・`incident_archive.json`、トップの更新履歴と「経緯」）に残る
  「封鎖◯日目」「二重封鎖◯日目」は**書き換えない**。新しく書く文だけに適用する

### ルール：人名の表記（必須）

| 人物 | 正しい表記 | 禁止表記 |
|---|---|---|
| 中国国家主席 | 習近平 | Xi、Xi Jinping のみ（日本語文中） |
| 米国大統領 | トランプ大統領 | Trump のみ（日本語文中） |

- 日本語コンテンツ内では人名を**必ず日本語表記**にする
- 英語表記は括弧内補足（例：習近平（Xi Jinping））としてのみ許容
- TICKER・シナリオ・30秒カラム（主な動きを含む）・速報インシデント 全セクションで適用
