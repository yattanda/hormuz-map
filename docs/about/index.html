1. チョークポイント・ラボとは

チョークポイント・ラボ（英表記：Chokepoint Lab、以下「本サイト」）は、地政学・エネルギー安全保障・海上物流の交差する領域で起きる危機を、継続的に整理し、可視化して提供する情報メディアです。世界の交易には、そこが塞がれると物流全体に影響が及ぶ「チョークポイント（隘路）」と呼ばれる要衝が存在します。本サイトは、こうした要衝で進行する事象を、日次で更新するダッシュボードと解説記事の形で追跡します。

「ラボ（Lab）」という名称には、断定を避け、根拠を明示し、事実と推定と分析を区別して検証していく場でありたい、という編集姿勢を込めています。

2. 扱う領域

本サイトは特定の一事件のためのサイトではなく、地政学・エネルギー・海上物流の危機を継続的に扱う常設のメディアとして運営しています。個々のテーマは、事件名ではなく地理・領域の名前で整理します。

第一号のテーマとして「ホルムズ海峡」を扱っています。通航状況、代替ルート、原油価格、石油備蓄、日本関係船の状況などを、情報源と基準日を明示しながら追跡しています。今後、他の要衝へとテーマを広げていく予定です。

3. 編集の姿勢

本サイトは、情報の信頼性を最優先に運営しています。基本的な姿勢は次のとおりです。

  • 情報源、取得日、基準日、対象範囲を、要素ごとに明示します。
  • 政府機関・国際機関・軍・企業の公式発表などの一次情報を優先し、報道は事実確認の手段として扱います。
  • 事実、推定値、編集部による分析・見解を、明確に区別して示します。
  • 推定値には、算出の根拠と前提を併記します。
  • 過度に不安を煽る表現や、根拠のない断定を避けます。

本サイトが提供する情報は、公式情報の代替となるものではなく、投資判断・事業判断の根拠として利用されることを想定していません。詳しくは免責事項をご確認ください。

4. AIの利用と人間による検証

本サイトの情報収集・整理の一部には、AIを活用しています。公開されている情報の収集や下書きの作成にAIを用いる一方で、公開するかどうかの判断は必ず人間が行っており、内容が自動的に公開される仕組みは設けていません。ただし、日次の更新など定型的なものについては、公開前の内容確認を省略し、公開後に確認する運用としています。この工程の詳細と、そこから生じる制約への対応については、編集方針で説明しています。

また、掲載する数値には、実測されたデータのほか、AIによる推定値が含まれる場合があります。推定値については、それが推定であること、および算出に用いた手段・前提を明示する方針です。AIの活用方法と検証の具体的な手順については、 編集方針のページで改めてご説明します。
