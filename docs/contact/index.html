お問い合わせ

最終更新：2026年9月1日

チョークポイント・ラボ（以下「本サイト」）へのお問い合わせは、ご用件に応じて次の窓口をご利用ください。ご用件に合った窓口をお選びいただくことで、確認と対応が早くなります。

1. 記載内容の誤り・訂正のご指摘

本サイトに掲載している数値、日付、固有名詞、出典などに誤りを発見された場合は、訂正・誤りのご指摘フォームよりお知らせください。フォームでは、該当ページのURL、該当箇所、ご指摘の内容、根拠となる出典URLをうかがっています。

いただいたご指摘は内容を確認し、訂正が必要と判断した場合は、訂正の内容と日時を記録して公開します。ご希望に応じて、訂正履歴に謝辞としてお名前（表示名）を掲載することもできます。

2. 取材・提携・権利に関するお問い合わせ

取材のご依頼、掲載内容の引用・転載のご相談、提携のご提案、著作権その他の権利に関するご照会は、次のアドレスまでご連絡ください。

  • contact@chokepointlab.com

お問い合わせの際は、差し支えのない範囲で、ご所属・お名前・ご用件の概要をご記載いただけますと、確認がスムーズです。権利に関するご照会の場合は、対象となるページのURLと該当箇所をあわせてお知らせください。

3. 個人情報の取り扱いに関するご請求

本サイトが取得した個人情報について、開示、内容の訂正、追加、削除、利用の停止をご希望の場合も、上記のメールアドレスで承ります。ご本人であることを確認したうえで、法令の定めに従って対応します。個人情報の取り扱いの詳細はプライバシーポリシーをご確認ください。

4. お答えできないこと

本サイトは情報提供を目的とした媒体であり、次のようなお問い合わせにはお答えできません。あらかじめご了承ください。

  • 個別の投資判断・事業判断に関するご相談、推奨銘柄や売買時期のお問い合わせ
  • 今後の情勢に関する断定的な見通しのご提供
  • 本サイトが公開していないデータの個別提供、または未公開情報のご照会
  • 緊急時の安否確認、渡航可否の判断など、公的機関がお答えすべき事項

本サイトの情報の位置づけについては免責事項をご確認ください。緊急時・危機時の判断にあたっては、必ず一次情報および公的機関の公式発表をご確認ください。

5. 返信について

本サイトは個人により運営されており、いただいたすべてのお問い合わせに返信をお約束することはできません。内容によっては、返信いたしかねる場合や、お時間をいただく場合があります。

なお、訂正のご指摘については、返信の有無にかかわらず内容を確認し、訂正が必要な場合はサイトへ反映します。ご指摘そのものが無視されることはありません。

6. 運営者

本サイトは「チョークポイント・ラボ」の名称で個人により運営されています。運営の目的と編集の姿勢についてはこのサイトについてをご覧ください。
