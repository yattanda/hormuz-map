プライバシーポリシー

最終更新：2026年10月10日

1. 基本方針

チョークポイント・ラボ（以下「本サイト」）は、利用者の個人情報を尊重し、その保護の重要性を認識したうえで、個人情報の保護に関する法律その他の関係法令を遵守します。本サイトは、必要のない個人情報を取得しないこと（データ最小化）を基本方針とし、取得する情報の範囲と利用目的を本ポリシーに明示します。

2. 取得する情報と取得方法

本サイトが利用者の個人情報を取得するのは、次の場合に限られます。閲覧のみの場合、本サイトが氏名・住所・メールアドレス等を取得することはありません。なお、運営者が自身の YouTube チャンネルへの動画投稿に使用するツールについては、第7章をご覧ください。

(1) 訂正・誤りのご指摘フォーム

本サイトの記載内容に関するご指摘を受け付けるため、Google フォームを利用したフォームを設置しています。このフォームでは、指摘の種類、該当ページのURL、該当箇所、指摘内容、根拠となる出典URLのほか、確認日・基準日、訂正履歴への謝辞掲載の可否、謝辞に使用する表示名を入力いただきます。どの項目が必須であるかは、フォームの画面上でご確認ください。

また、このフォームではメールアドレスの入力が必須となっています。これは利用している Google フォームの仕様によるもので、入力されたアドレスは、回答の控えの送信先および内容の確認が必要な場合のご連絡先としてのみ使用します。それ以外の目的に利用することはありません。

このフォームは Google LLC が提供する Google フォームであり、入力された内容（メールアドレスを含む）は、同社が管理するサーバー上に保存されます。保存された回答は、本サイトの運営者が閲覧します。Google LLC における情報の取り扱いについては、同社のプライバシーポリシーをご確認ください。

なお、フォームの利用にあたって Google アカウントへのログインは求めていません。

(2) お問い合わせ

取材・提携・権利に関するご照会などのお問い合わせは、電子メール（contact@chokepointlab.com）で受け付けています。この場合、送信者のメールアドレスおよびメール本文に記載された情報を取得します。

当該アドレス宛のメールは、Cloudflare, Inc. が提供するメール転送サービスを経由し、Google LLC が提供するメールサービス上で受信・保管されます。

(3) アクセスログ

本サイトは GitHub, Inc. が提供する GitHub Pages 上で公開されています。同社は、サービスの提供およびセキュリティの確保のために、アクセス元のIPアドレス等を含むログを取得する場合があります。これは同社が同社の責任において行うものであり、本サイトの運営者は、これらのログを閲覧する手段を有していません。

3. 利用目的

取得した情報は、次の目的にのみ利用します。

  • ご指摘いただいた内容の確認、および記載の訂正
  • ご指摘・お問い合わせへの回答・ご連絡
  • 訂正履歴への反映（謝辞への表示名の掲載は、ご本人が可と回答された場合に限ります）

これらの目的の範囲を超えて利用することはありません。営業目的の連絡やメールマガジンの配信には利用しません。

4. Cookie等の取り扱い

本サイトは、後述するアクセス解析（Google アナリティクス）のために、本サイトのドメインで発行される Cookie を使用しています。具体的には「_ga」および「_ga_T0KCXP29E5」という名称の Cookie で、利用者のブラウザを識別し、同一の利用者による複数回の閲覧をまとめて集計するために用いられます。既定の保存期間は2年です。これらの Cookie に、氏名・メールアドレス等の個人を直接識別する情報は含まれません。

また、後述する外部サービスのコンテンツを表示する過程で、それらの提供事業者が Cookie 等を設定する場合があります。

Cookie の受け入れは、お使いのブラウザの設定により拒否することが可能です。拒否した場合でも、本サイトの主要な閲覧に支障はありませんが、一部の外部コンテンツ（チャート等）が正しく表示されないことがあります。アクセス解析の無効化については第6章をご覧ください。

ブラウザのローカルストレージ・セッションストレージへの保存は行っていません。

5. 外部サービスへの情報送信

本サイトのページを表示する際、ブラウザは次の外部サービスに接続します。この接続に伴い、利用者のIPアドレス、ブラウザの種類、参照元のページなどの情報が、各サービスの提供事業者に送信されます。これは各社が自らの責任において取得するものであり、本サイトの運営者がこれらの情報を受け取ることはありません。

  • Google LLC（Google アナリティクス／googletagmanager.com）… アクセス解析。詳細は第6章
  • TradingView（tradingview.com）… 原油価格等のチャートウィジェットの表示
  • CARTO および OpenStreetMap… 地図の背景タイルの配信
  • GitHub, Inc.… 本サイトのホスティング
  • Google LLC（Google フォーム）… 訂正指摘フォームを開いた場合

各サービスにおける情報の取り扱いについては、それぞれの事業者が定めるプライバシーポリシーをご確認ください。

6. アクセス解析・広告配信について

本サイトは、閲覧状況の把握と改善のために、Google LLC が提供するアクセス解析サービス「Google アナリティクス（GA4）」を使用しています。導入日は2026年9月3日です。当初はトップページのみに設置していましたが、2026年9月22日からは、解説記事・図解・アーカイブ、および本ページを含む各種方針ページなど、本サイトのすべてのページに設置しています。なお、トップページに埋め込んでいるデータダッシュボード（別のドメインから配信）には設置していません。

Google アナリティクスは、第4章に記載した Cookie により利用者のブラウザを識別し、閲覧されたページ、参照元、ブラウザの種類、端末の種別、およびアクセス元のIPアドレスから推定されるおおよその地域といった情報を収集します。IPアドレスそのものは、Google アナリティクス4の仕様により記録・保存されません。収集された情報は Google LLC が管理するサーバー上に保存され、同社のプライバシーポリシーに基づいて取り扱われます。本サイトの運営者が閲覧できるのは、個人を特定しない集計されたレポートのみです。

本サイトの Google アナリティクスは、Google の広告サービスとの連携を行っていません。収集された情報が広告の配信や広告効果の測定に利用されることはありません。

収集を望まれない場合は、次のいずれかの方法で無効化できます。

  • お使いのブラウザで Cookie を拒否する、またはトラッキング防止機能を有効にする
  • Google が提供するGoogle アナリティクス オプトアウト アドオンを導入する

広告配信は行っていません。行動履歴に基づく広告（パーソナライズ広告）の配信も行っていません。将来導入する場合には、事前に本ポリシーを改定し、利用するサービス名、取得される情報の種類、および利用者による無効化（オプトアウト）の方法を本ページに明記します。

7. YouTube API Services の利用（運営者の動画投稿ツール）

本サイトの運営者は、運営者自身の YouTube チャンネル「危機地図チャンネル」へ動画を投稿するために、YouTube API Services を利用する投稿ツール「Chokepoint Lab Uploader」（以下「本ツール」）を使用しています。本ツールは運営者が自身のコンピューター上でのみ使用するものであり、一般の利用者には提供していません。

(1) YouTube API Services と Google のプライバシーポリシー

本ツールは YouTube API Services を利用しています。本ツールを使用する者は、YouTube 利用規約に拘束されることに同意したものとします。YouTube API Services を通じて扱われる情報には、Google のプライバシーポリシーが適用されます。

(2) 本ツールがアクセス・保存する情報

本ツールは、Google アカウントによる認可（OAuth 2.0）を受けて、運営者の YouTube チャンネルへ動画をアップロードする権限のみを使用します。本ツールがアクセスし、保存する情報は次のとおりです。

  • 認可により Google から発行されるアクセストークンおよびリフレッシュトークン（運営者のコンピューター内にのみ保存します）
  • アップロードする動画ファイル、サムネイル画像、および題名・説明・公開設定などの動画情報（いずれも運営者自身が作成したものです）
  • アップロード後に YouTube から返される動画のID

本ツールは、他の YouTube 利用者、視聴者、チャンネル登録者の情報にはアクセスしません。

(3) 情報の利用と共有

前項の情報は、運営者のチャンネルへ動画を投稿するためにのみ使用します。Google LLC 以外の第三者に送信・共有することはありません。本ツールは広告を配信せず、第三者に広告その他のコンテンツを配信させることもありません。また、本ツールは利用者の端末やブラウザに Cookie その他の情報を保存しません。

(4) アクセスの取り消しと情報の削除

本ツールに与えたアクセス権限は、Google のセキュリティ設定ページ（https://security.google.com/settings/security/permissions）からいつでも取り消すことができます。権限が取り消された場合、または本ツールの使用を終える場合には、認可に基づいて取得・保存した情報（トークン、および YouTube から返された動画IDの記録）を、7日以内に削除します。

(5) お問い合わせ

本ツールにおける情報の取り扱いに関するご質問・苦情は、第12章の窓口（contact@chokepointlab.com）までご連絡ください。

Chapter 7 in English: Use of YouTube API Services (the operator's video upload tool)

This English text is provided for reference. It has the same content as the Japanese text of Chapter 7 above.

The operator of this website uses “Chokepoint Lab Uploader” (the “Tool”), an upload tool that uses YouTube API Services, to upload videos to the operator's own YouTube channel, “危機地図チャンネル” (Crisis Map Channel). The Tool is used only by the operator on the operator's own computer and is not offered to the public.

(1) YouTube API Services and the Google Privacy Policy. The Tool uses YouTube API Services. By using the Tool, users agree to be bound by the YouTube Terms of Service. Information handled through YouTube API Services is subject to the Google Privacy Policy.

(2) Information the Tool accesses and stores. With authorization through a Google account (OAuth 2.0), the Tool uses only the permission to upload videos to the operator's YouTube channel. The Tool accesses and stores the following information:

  • The access token and refresh token issued by Google upon authorization (stored only on the operator's computer)
  • The video files, thumbnail images, and video information such as titles, descriptions and privacy settings that are uploaded (all created by the operator)
  • The video IDs returned by YouTube after upload

The Tool does not access information about other YouTube users, viewers or channel subscribers.

(3) Use and sharing of information. The information above is used only to upload videos to the operator's channel. It is not sent to or shared with any third party other than Google LLC. The Tool does not serve advertisements and does not allow third parties to serve advertisements or other content. The Tool does not store cookies or any other information on users' devices or browsers.

(4) Revoking access and deleting information. Access granted to the Tool can be revoked at any time via the Google security settings page (https://security.google.com/settings/security/permissions). When access is revoked, or when the operator stops using the Tool, the information obtained and stored under the authorization (the tokens and the records of video IDs returned by YouTube) will be deleted within 7 days.

(5) Contact. Questions or complaints about how the Tool handles information may be sent to the contact point in Chapter 12 (contact@chokepointlab.com).
