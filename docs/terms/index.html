1. 本規約について

本規約は、チョークポイント・ラボ（以下「本サイト」）の利用、および本サイトの運営者が使用する動画投稿ツール「Chokepoint Lab Uploader」（以下「本ツール」）の利用について定めるものです。

2. 本サイトの利用

本サイトの閲覧にあたっての条件は、免責事項、プライバシーポリシー、および編集方針に定めるとおりです。

3. 動画投稿ツール（YouTube API Services の利用）

本ツールは、本サイトの運営者が自身の YouTube チャンネル「危機地図チャンネル」へ動画を投稿するために使用するもので、YouTube API Services を利用しています。本ツールは運営者が自身のコンピューター上でのみ使用するものであり、一般の利用者には提供していません。

本ツールを使用する者は、本ツールを使用することにより、YouTube 利用規約（https://www.youtube.com/t/terms）に拘束されることに同意したものとします。

本ツールにおける情報の取り扱いは、プライバシーポリシーの第7章に定めるとおりです。YouTube API Services を通じて扱われる情報には、Google のプライバシーポリシーが適用されます。

Section 3 in English: Video upload tool (use of YouTube API Services)

This English text is provided for reference. It has the same content as the Japanese text of Section 3 above.

“Chokepoint Lab Uploader” (the “Tool”) is used by the operator of this website to upload videos to the operator's own YouTube channel, “危機地図チャンネル” (Crisis Map Channel), and uses YouTube API Services. The Tool is used only by the operator on the operator's own computer and is not offered to the public.

By using the Tool, users agree to be bound by the YouTube Terms of Service (https://www.youtube.com/t/terms).

How the Tool handles information is described in Chapter 7 of the Privacy Policy. Information handled through YouTube API Services is subject to the Google Privacy Policy.

本サイトは、本規約を必要に応じて変更することがあります。変更後の内容は、本ページに掲載した時点から効力を生じます。
