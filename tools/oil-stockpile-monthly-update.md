# 石油備蓄コラム 月次追記手順

対象：`docs/articles/oil-stockpile-monthly-trend.html`（📉 石油備蓄はどう推移したか──月次まとめとグラフで見る現在地）

毎月4日に、前月末時点の値を追記する。
速報は「◯日時点」の値が3日後に公表されるため（例：8月31日時点 → 9月3日公表）、月末当日には月末値がまだ無い。

## 1. データを取得する

- 一次資料：資源エネルギー庁「石油備蓄の状況（推計値の速報）」
  `https://www.enecho.meti.go.jp/statistics/petroleum_and_lpgas/pl001/pdf-oil-res/oil_daily.pdf`
- **curl / WebFetch では取得できない**（bot対策で 403 / 202 が返る）。
  アプリ内ブラウザ（`mcp__Claude_Browser__*`）でまず
  `https://www.enecho.meti.go.jp/statistics/petroleum_and_lpgas/pl001/` を開き、次に PDF の URL へ移動する。
  そのページ上で `fetch(location.href)` して、pdf.js（`cdn.jsdelivr.net/npm/pdfjs-dist`）でテキストを抽出する
- PDF は「令和8年M月D日（M月D日時点）」の見出しの**後ろ**に、国家・民間・産油国共同・合計が並ぶ。
  見出しと値の対応を取り違えない
- 使うのは**前月末日時点**の値。月末日の値が無い場合（公表されない日）は直前の日を使い、表に日付を明記する

## 2. 記事を更新する

1. 月次表：前月の「直近速報」行を「M月末（速報）」行に置き換える（前月末値で差し替え）。
   新しい「直近速報」行は置かない（月末値が最新の行になる）。備考欄は数値から読める事実だけを書く
2. 折れ線グラフ（SVG）：点を1つ追加し、x座標を 60〜660 に等間隔で配り直す。
   y座標は `y = 260 − (日数 − 190) × 3.385`。190日を下回ったら軸の目盛りを作り直す
3. グラフ下の注記・`aria-label`・リード文・「まず結論」・メタ description（3か所＋構造化データ）の「現在◯日分」を更新
4. 「月ごとの経緯」に前月の段落を追加。日付には `<span class="at-the-time">` を付ける
5. 要点ボックス・結論を必要に応じて更新
6. 最終更新日（本文の `article-meta` と構造化データ `dateModified`）を作業日にする

## 3. 周辺を追従させる

- `docs/index.html` の「石油備蓄の月次推移まとめコラムカード」のサブタイトルと要約
- `docs/articles/index.html` の一覧カードの `idx-lead`
- `docs/sitemap.xml` の該当 URL の `lastmod`
- `docs/index.html` の「30秒で全体像」内の特別解説ピル（`📉 石油備蓄推移`）の `data-updated` を、記事の `dateModified` と同じ日付にする。
  これで「◯月更新」の札が30日間表示される

## 4. 書いてはいけないこと

- 速報資料に無い「要因」を推測で書かない（例：国家備蓄が1日分減った理由）。
  政策の動きを書く場合は、Web 検索で確認した一次資料・報道に限り、出典を本文に示す
- 他セクション（`docs/index.html` の他の箇所にある備蓄日数の記載など）は、この作業では触らない
