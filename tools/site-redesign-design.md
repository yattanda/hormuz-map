## 1. 画面の作法

題材は艦艇の識別表と航路標識。飾りではなく、区切りと状態の示し方をそこから借りる。

- 段は太い罫（上に3px）で切る。段の中の区切りは細い罫。箱・角丸・影・グラデーションで区切らない
- 数字は縦長の書体で大きく。数字の下に必ず「いつ時点・どこの発表か」を置く
- 絵は図版として扱う。大きく見せる場所（コラムの入口など）と、文中の小さな印を混ぜない
- 状態は色の面で示す：赤＝危険、橙＝警戒、黄＝注記、緑＝平常、枠だけ＝判断なし。色だけに頼らず、必ず文で状態を書く
- 色面を使うのは状態だけ。装飾のために赤・橙・黄・緑を使わない

決定（運営者・2026-10-12）：いまのルート表の 🟠 と 🟡 は分けたまま引き継ぐ。橙を4色目の状態の色にする。

決定（運営者・2026-10-19）：状態ではない色丸（ルート表の 🟣 🟤、シナリオD の ⚫）はやめる。ルート表の1列目は状態の色面にそろえる。シナリオは A 緑 `--c-ok`・B 黄 `--c-warn`・C 橙 `--c-alert`・D 赤 `--c-danger`（札の文字は `--c-on-*`）。

## 2. アイコンの使い分け

| 種類 | 使う場所 | 大きさ |
|---|---|---|
| A 識別シルエット（1色） | 文の中、一覧の行頭、表の中 | 16〜24px |
| B 3色の塗り分け | 見出し、カード、記事の入口 | 28px 以上 |
| C 徽章 | 地図の印と凡例、ブランドの場面（ロゴまわり、favicon、`og:image`、動画のサムネイル） | 24px 以上 |

- 3種類とも同じ形から作る（塗り分ける色を替えるだけ）。SVG の `<symbol>` に置き、色は変数 `--a`（主）・`--b`（差し色）・`--c2`（副）・`--k`（地で抜く色）で渡す
- 描き込んだ絵は 20px では潰れる。A には細部を省いた簡略版を別に用意する（2026-10-16 に5題材を作成・アイコンの見本の「A の簡略版」。見本はリポジトリ外）
  - 24 の地割り（`viewBox="0 0 24 24"`）で描き、記号の名前は `a-tanker`・`a-warship`・`a-mine`・`a-anchor`・`a-barrel`
  - 線と隙間は 1.2 単位以上（16px で約 0.8px）。抜きは地の色で塗らず穴をあける（evenodd）ので、`--a` の1色だけで、どの地の上でも使える
  - 形を決めている所だけ残す：タンカーは後ろの船橋と煙突・長い平らな甲板、軍艦は段になった上部構造・マスト・前の砲、機雷は球と5本の角と係維索、錨は輪・横棒・腕と爪、原油は胴・2本の帯と油滴
  - 16px と 20px で実際に描いた画素を拡大して、明るい地と暗い地の両方で確かめた。もとの絵は細い線が灰色ににじむ。簡略版は5つとも形が残る。機雷は最初の形では角が球に埋もれたので、球を小さく角を長くした
  - 新しい題材を足すときも、B の絵と簡略版の2つを作る
- 絵文字は使わない。国旗の絵文字も使わず、国名の文字で書く（R3・2026-10-16 決定）
- コードで描く絵は、形と塗り分けまで。陰影や質感が要る絵（ロゴ、`og:image`、サムネイル）は Canva で作る（2026-10-19 追記：Canva のコネクタでは書体を当てられなかったため、ロゴと `og:image` はリポジトリ外の道具〈Playwright〉でローカルの書体を当てて PNG に描いた。質感は付けないことにした）

### 2-3. ブランド素材（2026-10-19）

- 印（CL2）：描き起こしの C（太さ 7・口 ±25°）＝湾の岸（本文の色）、L（C と同じ高さ）＝陸（補助の色）、航路の矢印（差し色の破線）が C の内側から口を抜け、L の縦画の左に沿って L の上端より上まで上がる。64 の地割り。暗い地の上では印の四角を地に溶かす
- favicon 用の簡略形：24 の地割り。破線をやめて実線にし、矢印は C の口から出す（C の内側を横切る実線にすると、16px で C が「e」に見えるため）。16・32px の暗いタブ・明るいタブで C・L・矢印が読める
- 横組み：印＋「チョークポイント・ラボ」（BIZ UDPゴシック 700）＋「CHOKEPOINT LAB」（IBM Plex Sans Condensed 600・字間を広く）。左寄せ
- favicon：16・32・48px を1つの `favicon.ico` に、180px の `apple-touch-icon.png`。置くのは課題7 の観測明けの PR
- `og:image`：1200×630・PNG・質感なし（約 50 KB）。上に太い罫・左寄せ。文字と印は左右 72px・上下 60px より内側。ハブは右に印を大きく、法務ページなどは共通の1枚

- **海岸線の角ばりは、いまのサイトにもある**（同じ国の形のデータを、CARTO の上にほぼ不透明で重ねているため）。CARTO をやめても悪くはならない。細かくするのは、CARTO をやめるかどうかとは別の改善

- サイトが地点ジャンプで使うズームは 3〜9。ズーム 10 は手で拡大したときだけ

### 国名の置き方（2026-10-16・試作で確認）

いまのサイトは、国名を国ごとに決まった1点（首都の近くが多い）に、重なりの調整なしで出している。CARTO とは関係なく自前で出しているので、CARTO をやめても国名は残る。

この出し方を試作にそのまま入れて、8か所（ホルムズ海峡・ペルシャ湾・バベルマンデブ・スエズ・紅海・パナマ・マラッカ・津軽）×ズーム 4〜10 で、重なりを数えた（地名は重なったら後から置くほうを省く）。

| 問題 | 結果（いまの出し方） |
|---|---|
| 国名が首都を消す | ズーム 4〜6 で、リヤド・バグダード・サヌア・ドーハ・マナマ・クウェート市・エルサレムなどが国名とぶつかって消える |

### 描き方（試作で確認済み）

- 層は3つ。下から、(A) Natural Earth の陸地と、範囲を海の色で塗る面／(B) OSM の陸地と、その上にだけ重ねる国の色／(C) 湖・川・海岸線・国境
- (B) は canvas の `source-atop` を使う。OSM の陸地を先に塗り、湾岸の9か国の面を「粗い国の形の外へ 2.5 km 分だけ広げて」重ね、隣の国を塗り直す。これで、細かい海岸線のまま国ごとの色分けが保てる。最後に島を、組み立てのときに決めた国の色で塗り直す（2.5 km より沖の島のため。上の「国の色の確認と、沖の島の直し」）
- 間引きは 0.0008度（約80〜90 m）、約200 m 四方より小さい島は省く。最大の拡大（1画素 約137 m）でも差は見えない
- 範囲の縁の細い線は、海の色の面を 0.002度 内側に置いて消した
- 本番（D3）では、国ごとの面をあらかじめ作っておく方法もある（図形の演算ができる道具が要る）。どちらにするかは D3 で決める
