## 1. 画面の作法

題材は艦艇の識別表と航路標識。飾りではなく、区切りと状態の示し方をそこから借りる。

- 段は太い罫（上に3px）で切る。段の中の区切りは細い罫。箱・角丸・影・グラデーションで区切らない
- 数字は縦長の書体で大きく。数字の下に必ず「いつ時点・どこの発表か」を置く
- 絵は図版として扱う。大きく見せる場所（コラムの入口など）と、文中の小さな印を混ぜない
- 状態は色の面で示す：赤＝危険、橙＝警戒、黄＝注記、緑＝平常、枠だけ＝判断なし。色だけに頼らず、必ず文で状態を書く
- 色面を使うのは状態だけ。装飾のために赤・橙・黄・緑を使わない

決定（運営者・2026-10-12）：いまのルート表の 🟠 と 🟡 は分けたまま引き継ぐ。橙を4色目の状態の色にする。

## 2. アイコンの使い分け

| 種類 | 使う場所 | 大きさ |
|---|---|---|
| A 識別シルエット（1色） | 文の中、一覧の行頭、表の中 | 16〜24px |
| B 3色の塗り分け | 見出し、カード、記事の入口 | 28px 以上 |
| C 徽章 | 地図の印と凡例、ブランドの場面（ロゴまわり、favicon、`og:image`、動画のサムネイル） | 24px 以上 |

- 3種類とも同じ形から作る（塗り分ける色を替えるだけ）。SVG の `<symbol>` に置き、色は変数 `--a`（主）・`--b`（差し色）・`--c2`（副）・`--k`（地で抜く色）で渡す
- 描き込んだ絵は 20px では潰れる。A には細部を省いた簡略版を別に用意する（2026-10-16 に5題材を作成・アイコンの見本の「A の簡略版」。見本はリポジトリ外）
  - 24 の地割り（`viewBox="0 0 24 24"`）で描き、記号の名前は `a-tanker`・`a-warship`・`a-mine`・`a-anchor`・`a-barrel`
  - 線と隙間は 1.2 単位以上（16px で約 0.8px）。抜きは地の色で塗らず穴をあける（evenodd）ので、`--a` の1色だけで、どの地の上でも使える
  - 形を決めている所だけ残す：タンカーは後ろの船橋と煙突・長い平らな甲板、軍艦は段になった上部構造・マスト・前の砲、機雷は球と5本の角と係維索、錨は輪・横棒・腕と爪、原油は胴・2本の帯と油滴
  - 16px と 20px で実際に描いた画素を拡大して、明るい地と暗い地の両方で確かめた。もとの絵は細い線が灰色ににじむ。簡略版は5つとも形が残る。機雷は最初の形では角が球に埋もれたので、球を小さく角を長くした
  - 新しい題材を足すときも、B の絵と簡略版の2つを作る
- 絵文字は使わない。国旗の絵文字も使わず、国名の文字で書く（R3・2026-10-16 決定）
- コードで描く絵は、形と塗り分けまで。陰影や質感が要る絵（ロゴ、`og:image`、サムネイル）は Canva で作る

いまある題材：タンカー・軍艦・機雷・錨・原油。絵文字は71種類あるので、D1 で必要な題材を洗い出す。

### J1 の判断材料（2026-10-12 調査）

推奨（10/12 時点。その後の試作で上の要点になった）：**CARTO のタイルをやめ、すでに置いてある `docs/data/countries.geojson`（Natural Earth 由来・1.14 MB）だけで描く。**

- いまの地図は、CARTO のタイルの上に全部の国の面を `fillOpacity:0.96` で重ねている（`docs/hormuz/index.html` 3807〜3828行）。国名と海域のラベルも自前。CARTO が実際に見せているのは、海の色と、都市名などの細かい地名だけ
- やめると：色を自由に決められる／費用なし／外部への通信が1社減り、`/privacy/` 第5章から CARTO と OpenStreetMap の行を外せる／API キーの直書きが消える（J2 も閉じる）
- 失うもの：都市名・細かい地名・川・湖・道路。要るものは自前のラベルで足す
- 気になりうる点：いちばん拡大すると海岸線の折れが見える（イラン側の海峡部は頂点の間隔がおよそ 2.7 km）。気になれば湾岸だけ細かいデータに差し替える
- 変更の規模：`L.tileLayer` 2本の削除、`#map` の背景色、国の面とラベルの色、クレジット、`/privacy/` の1行。追加ファイルなし

CARTO の規約（`https://carto.com/legal/basemap-terms/`・最終更新 2026-09-29・2026-10-12 に本文を確認）：
- 広告収入のあるサイトは Commercial Use（第1条）
- 自分の API キーを使えば、Commercial Use でも月100万タイルリクエストまで無料（第3条 b・第12条 d）。それを超えると月500ドルから（第3条 e）
- 2026-09-23 より前に発行されたキーは 11/30 まで非商用の枠（月500万）で使え、12/1 から月100万が適用（第3条 f）
- 無料の提供は、CARTO の判断でいつでも予告なく止められる（第3条 c）
- つまり「商用は Enterprise が必要」という認識（作業順の課題17）は、いまの規約とは合わない。AdSense のために CARTO をやめる必要はなくなった。やめる理由は、色を自分で決めたいこと・外部依存を減らすこと

ほかの候補（Stadia Maps・MapTiler・Protomaps・OpenStreetMap 標準タイルほか）は、費用がかかるか、色を決められないか、GitHub Pages の容量に収まらない見込み。各社の規約は要約経由で読んだだけなので、採るときは原文を確かめる。

### 運営者の条件（2026-10-12）と、進める前に確かめること

方向は「CARTO をやめる」。条件は4つ：(0) 色をもう少し明るく（見本に明るさ3段を足した）／(2) 海岸線の角ばりをなくす／(3) 都市名・地名・川・湖を出す／気に入らなければ戻せること。

調べて分かったこと（ソースで確認）：
- いまの地図で都市名・地名を出しているのは CARTO の `dark_only_labels`（国の面より上・不透明度 0.85）
- 川と湖は、いまの地図でもほぼ見えていない。国の面が上から覆うため（`docs/hormuz/index.html` 4029〜4031行のコメントにも「国土ポリゴンが陸地色で塗り潰すため、そのままでは湖が見えない」とあり、パナマのガトゥン湖だけ専用のペインで自前に描いている）。つまり川と湖は「失う」のではなく「新しく足す」もの
- 印・線・面を ±360° に複製する仕組み（課題45）があり、新しく足す層もこの仕組みに乗せる必要がある

手戻りを避けるために、実装の前に試作で確かめる：
1. Natural Earth 10m の海岸線・川・湖・都市（日本語名つき）を、ズーム 2〜10 で必要な分だけに絞ると何 MB になるか
2. 湾岸の海岸線が、いちばんの拡大で滑らかに見えるか
3. 都市名が重ならずに出せるか（ズームごとに出す数を絞る）。日本語名の欠けと誤りがどの程度あるか
4. スマホで重くならないか（描く点の数と、±360° の複製）
試作の結果が悪ければ、中間案に切り替える：色と形は自前、地名だけ CARTO の `dark_only_labels` を残す（外部への通信は残るが、見た目の主導権は取れる）。

戻せる形：背景の種類を1か所の設定（自前／CARTO）で切り替えられるように入れ、CARTO のタイルの行は消さずに残す。`/privacy/` 第5章の CARTO の行は、切り替えが定着するまで外さない（外すのは別の回）。気に入らなければ設定を戻すだけで済む。

### 試作の結果（2026-10-12）

Natural Earth 10m（`github.com/nvkelso/natural-earth-vector`・パブリックドメイン）の6ファイル（約 48 MB）を取り、リポジトリ外の道具（`ne_build.py`）で絞った。明るさは「中間」（運営者の決定）。

| 確かめたこと | 結果 |
|---|---|
| 1. データの大きさ | 合計 約3.6 MB（国の形と島 1.36／都市名 0.35／川 1.16／湖 0.75）。いまは国の形 1.14 MB＋CARTO のタイル画像。川と湖はまだ削れる（全世界の分の間引き） |
| 2. 海岸線の滑らかさ | **Natural Earth では足りない。**ホルムズ海峡付近の頂点の間隔は、いまのファイルが中央値 2.20 km、無加工の 10m が 1.69 km で、ほとんど変わらない。最大の拡大（ズーム 10）では、どちらも同じように角ばる。角を丸める処理（Chaikin・2回）で折れは消えるが、形そのものは細かくならない（ムサンダム半島の入り江は粗いまま） |
| 3. 都市名 | 全世界 7,342か所すべてに日本語名がある。重なりは、大きい都市から順に置いて、ぶつかるものを省く方法で収まった。湾岸の港のうち、ハサブ・ラスラファン・ジャスク・ハールク島・ゲシュム・バンダルレンゲ・ラスタヌラ・ドゥクムはデータに無く、自前で足す。サイトの表記と違う名前がある（例：データは「バンダレ・アッバース」）ので、読み替えの表が要る。川の日本語名はデータに無く、主な川だけ自前で足す |
| 4. 重さ | 世界を3つ並べて描いても動く（角を丸めた版で約42万点・canvas 描画）。スマホ実機は未確認 |

分かったこと：
- **海岸線の角ばりは、いまのサイトにもある**（同じ国の形のデータを、CARTO の上にほぼ不透明で重ねているため）。CARTO をやめても悪くはならない。細かくするのは、CARTO をやめるかどうかとは別の改善
- 本当に細かくするには、海峡のまわりだけ OpenStreetMap 由来の海岸線（ODbL・クレジット表示が必要。サイトはパナマの湖ですでに OSM 由来のデータを同梱している）に差し替える。あとから足せるので、先に CARTO を外しても手戻りにならない
- サイトが地点ジャンプで使うズームは 3〜9。ズーム 10 は手で拡大したときだけ

結論：CARTO をやめても手戻りはない。入れる順は (1) 色・川・湖・都市名を自前に（戻せる形で）→ (2) 海峡のまわりの海岸線を細かく、の2段。

### 国の色の確認と、沖の島の直し（2026-10-16）

**沖の島が国の色にならなかった。**描き方は「粗い国の形（Natural Earth）から 2.5 km 以内」だけを国の色に塗るため、それより沖の島は普通の陸の色になっていた。紅海のファラサン諸島（サウジ）、ズバイル諸島・ハニーシュ諸島（イエメン）、アブダビ沖の島などが当たる。

| 確かめ方 | 結果 |

| 細かい陸地の面ごとに内側の1点を取り、描き方どおりの色を計算 | 湾岸 622面のうち 301、紅海 854面のうち 251 が国の色にならない予測。パナマ・マラッカ・津軽は 0（範囲の中に湾岸の9か国がない） |

直し方：組み立て（`osm_build2.py`）で、範囲の中で閉じた輪（島）ごとに国を決めて `properties.i` に持たせる（Natural Earth の国の面の中ならその国、外ならいちばん近い国）。描くときは、2.5 km 広げる塗り方のあとに、島をその国の色で塗り直す。本土の海岸は今までどおり。

### 国名の置き方（2026-10-16・試作で確認）

いまのサイトは、国名を国ごとに決まった1点（首都の近くが多い）に、重なりの調整なしで出している。CARTO とは関係なく自前で出しているので、CARTO をやめても国名は残る。

この出し方を試作にそのまま入れて、8か所（ホルムズ海峡・ペルシャ湾・バベルマンデブ・スエズ・紅海・パナマ・マラッカ・津軽）×ズーム 4〜10 で、重なりを数えた（地名は重なったら後から置くほうを省く）。

| 問題 | 結果（いまの出し方） |
|---|---|
| 国名が首都を消す | ズーム 4〜6 で、リヤド・バグダード・サヌア・ドーハ・マナマ・クウェート市・エルサレムなどが国名とぶつかって消える |
| 拡大すると国名が出ない | 国ごとに1点なので、ズーム 7〜8 以上ではどの海峡でも国名が 0。地点ジャンプのズーム 9 では、どこにも国名が出ない |
| 国名の無い国 | 範囲に陸があるパナマ・コロンビア・スーダン・エリトリア・エチオピア・ヨルダン・インドネシア・タイが一覧に無い。マレーシアの点は海の上（北緯 4.2・東経 108） |

試作での直し方：
- 国名は、見えている範囲とその国の陸（Natural Earth の国の形）の重なりに 7×7 の候補点を取り、真ん中に近い順に、陸の上でほかの地名とぶつからない最初の点に置く。拡大しても、その国が画面にあれば国名が出る
- 置く順は、海の名前 → 自前の港 → サイトの本文に出てくる地名（36か所）とジュベル・アリ → 首都と州都など（国の首都が先） → 国名 → ほかの都市 → 川。国名は、本文の地名と首都・州都をよけて置く
- 国の首都と州都を分けるため、都市のデータに「国の首都」（2）を足した（州都は 1）
- 足した国：スーダン・エリトリア・エチオピア・ヨルダン・パナマ・コロンビア・インドネシア・タイ。シンガポールは都市名と同じなので足していない

### 描き方（試作で確認済み）

- 層は3つ。下から、(A) Natural Earth の陸地と、範囲を海の色で塗る面／(B) OSM の陸地と、その上にだけ重ねる国の色／(C) 湖・川・海岸線・国境
- (B) は canvas の `source-atop` を使う。OSM の陸地を先に塗り、湾岸の9か国の面を「粗い国の形の外へ 2.5 km 分だけ広げて」重ね、隣の国を塗り直す。これで、細かい海岸線のまま国ごとの色分けが保てる。最後に島を、組み立てのときに決めた国の色で塗り直す（2.5 km より沖の島のため。上の「国の色の確認と、沖の島の直し」）
- 間引きは 0.0008度（約80〜90 m）、約200 m 四方より小さい島は省く。最大の拡大（1画素 約137 m）でも差は見えない
- 範囲の縁の細い線は、海の色の面を 0.002度 内側に置いて消した
- 本番（D3）では、国ごとの面をあらかじめ作っておく方法もある（図形の演算ができる道具が要る）。どちらにするかは D3 で決める
